GramCare

GramCare is a healthcare application developed as a hackathon project to connect patients and doctors through a simple interface.

Technologies Used

- React
- Vite
- JavaScript
- CSS

How to Run the Frontend

1. Open the project folder in VS Code.

2. Open the terminal.

3. Install the dependencies:
   
   "npm install"

4. Start the development server:
   
   "npm run dev"

5. Open the local URL displayed in the terminal, usually "http://localhost:5173/".

Project Status

The frontend is under development. Backend integration and real doctor authentication will be connected as the project progresses.
